# Vehicle Rental Management System

## Project Overview
The Vehicle Rental Management System is a DBMS project designed to manage customers, vehicles, bookings, rentals, payments, maintenance, and employees.

## Objectives
- Manage customer information
- Manage vehicle and category details
- Track bookings and rentals
- Manage payment records
- Maintain vehicle maintenance records
- Maintain data consistency using primary and foreign keys

## Technologies Used
- Oracle Database
- Oracle APEX
- SQL

## Database Tables
1. CUSTOMER
2. VEHICLE_CATEGORY
3. VEHICLE
4. BOOKING
5. RENTAL
6. PAYMENT
7. MAINTENANCE
8. EMPLOYEE
